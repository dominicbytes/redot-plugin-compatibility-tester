# Contributing

Contributions are welcome after the repository is published.

1. Open an issue describing the behavior, evidence, and affected plan task.
2. Create a focused branch from `main`.
3. Add a failing test or deterministic fixture first.
4. Make the smallest coherent change.
5. Run the full local quality gate documented in [README.md](README.md).
6. Do not add a dependency, dynamic source form, engine download, build adapter, or weakened security limit without an explicit decision record.

Public pull-request CI runs repository-owned trusted fixtures only. Never submit private plugins, credentials, large binary fixtures, archive bombs, or third-party assets without compatible redistribution rights.

By contributing, you agree that your contribution is licensed under this repository's MIT License.
